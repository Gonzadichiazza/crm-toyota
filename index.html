Integración Automática con WhatsApp de tu Celular

¿Cómo funciona sin que tengas que avisarle manualmente?

Al conectar las notificaciones de WhatsApp de tu celular a tu base de datos Firebase, cada vez que un cliente te responde un mensaje, el celular envía el remitente/teléfono al CRM y la app lo marca sola como "Contestó" y detiene el reloj de 48 hs. Si no te responde en 48 hs, pasa solo a "No Compra" con fecha en la misma ventana.

Opción A: Android (MacroDroid / Tasker)
  1. Instala MacroDroid (Play Store) y dale permiso de Acceso a notificaciones y batería Sin restricciones.
  2. Disparador: Notificación recibida → App: WhatsApp / WhatsApp Business.
  3. Acción: Solicitud HTTP → Método POST → pega la URL de arriba.
  4. Cuerpo JSON: {"sender":"{not_title}","text":"{notification}"}
Opción B: iPhone (Atajos / Automatización)
  1. Abre la app Atajos (Shortcuts) → pestaña Automatización → +.
  2. Elige Mensaje o notificación de WhatsApp y activa Ejecutar inmediatamente.
  3. Agrega la acción Obtener contenido de URL con método POST y la URL de arriba.
  4. Envía en JSON la clave sender con el nombre o número del contacto.
